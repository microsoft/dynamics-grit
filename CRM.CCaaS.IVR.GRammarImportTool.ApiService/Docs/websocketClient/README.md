# GrITHub SignalR WebSocket Client (C#)

This ZIP file contains a C# implementation of a SignalR WebSocket client for connecting to the GrITHub server.

## Purpose
The client enables communication with the GrITHub SignalR hub, allowing you to send GRXML or ZIP files for conversion and receive progress updates and results in real time.

## Contents
- C# source code for the SignalR WebSocket client
- Example usage and connection instructions

## Usage
1. Extract the ZIP file.
2. Open the solution in Visual Studio.
3. Customize the ZIP and output paths as needed.

## Requirements
- .NET 8 or later
- Microsoft.AspNetCore.SignalR.Client NuGet package
